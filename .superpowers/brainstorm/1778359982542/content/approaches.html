How should we implement the theme?

Three approaches with different trade-offs

Approach A: CSS-Only (Recommended) ⭐

Override Keycloak's default theme CSS only. Uses existing FreeMarker templates but applies full myAwesomeApp styling via CSS. Fastest path.

Pros

  • Quick to implement (~1 day)
  • Survives Keycloak upgrades
  • Low maintenance

Cons

  • Limited HTML structure control
  • Can't add custom app header/footer

Approach B: Full FreeMarker Templates

Custom .ftl templates for login, register, and logout. Full control over HTML — can match the myAwesomeApp landing page structure exactly.

Pros

  • Complete design control
  • Can replicate app's nav/header

Cons

  • More verbose
  • May need updates when Keycloak changes template API
  • More to maintain

Approach C: Hybrid — Custom Templates + CSS

Override only the template wrappers (add app header/footer/background) but keep Keycloak's form markup. CSS handles the visual rest.

Pros

  • Good balance of control and maintainability
  • Adds app branding elements

Cons

  • Slightly more work than CSS-only
  • Partial template overrides
